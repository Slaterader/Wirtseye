# Security

## Reporting a security issue

Please do **not** post suspected security vulnerabilities, credential exposure, unsafe update behavior, or code-signing problems as public GitHub issues.

Until a dedicated private security-reporting channel is configured, contact the project maintainer privately and include the Wirt's Eye version and a concise description of the issue.

## Official releases

Only download Wirt's Eye from this repository's official **Releases** page once public distribution begins.

Published release hashes should be treated as part of the release record. Future releases are planned to use Windows Authenticode code signing as well as SHA-256 verification.
